# NeuroDifference — план до v4.0

Документ для агента-исполнителя. Читать вместе с `AGENTS.md`.
Цель не «больше», а **плотнее**: максимум ценности на единицу экрана и на единицу тапа.

Текущее состояние: v3.0.0, аудит 12/12, оценка стороннего ревью — 8/10.

---
## Рамка, без которой план бессмыслен

1. **Количество вкладок в навигации не растёт.** Нижняя навигация — 5 пунктов максимум.
   Всё новое уходит в глубину: разделы внутри, ⌘K-поиск, drawer. «Максимум вкладок»
   реализуется как максимум **достижимых разделов**, а не как максимум кнопок.
2. **Данные растут только с проверкой.** Каждая новая сущность проходит `#/dev/audit`.
   Аудит упал — правка откатывается, а не «починим потом».
3. **Сначала долги, потом красота.** Красиво оформленный баг остаётся багом.
4. **Один этап = один рабочий коммит.** Не смешивать фазы в одной правке.

## Ф2. Движение

- [ ] Все анимации только `transform` / `opacity`. Перевести:
      `width` (styles.css ~1398, ~1586) → `scaleX`;
      `background-position` (~1262, ~1572) → сдвиг псевдоэлемента через `translateX`;
      `filter: hue-rotate` (~1376) → статичный градиент;
      `box-shadow` (~1285) → `opacity` на отдельном слое.
- [ ] **Одна анимация на элемент.** Вход → удержание → выход = один keyframe-блок.
      Никаких двух `animation` на одном селекторе.
- [ ] Единая кривая: `--e-out` для входа, `--e-spring` только для «пружинных» акцентов.
      Никаких `linear` кроме прогресс-бара.
- [ ] Press-состояния: `transform: scale(.97)` на `:active`, 90 ms.
- [ ] Переходы между роутами: `document.startViewTransition`, если доступно,
      с graceful fallback (обычный рендер). Отключено при reduced-motion.

**Приёмка Ф2:** `grep -E "animation.*(width|background-position|filter|box-shadow)"` = 0.

## Ф3. Контент: препараты 148 → 250

Целевой потолок — 250 соединений / 75 классов. Дальше начинается мусор.

Порядок набора (по убыванию ценности):
1. **Антидепрессанты и анксиолитики:** вортиоксетин, вилазодон, миртазапин (есть?),
   атомоксетин, гидроксизин, буспирон, кломипрамин, ребоксетин.
2. **Антипсихотики:** карипразин, брекспипразол, локсапин, зотепин, сульпирид, амисульприд,
   клозапин (проверить), палиперидон LAI, галоперидол деканоат.
3. **Противосудорожные/стабилизаторы:** ламотриджин, вальпроат, карбамазепин, окскарбазепин,
   топирамат, габапентин, прегабалин, зонисамид, леветирацетам (нормотимики).
4. **СДВГ:** метилфенидат, дексметилфенидат, гуанфацин, клонидин.
5. **Деменция/когнитив:** донепезил, галантамин, ривастигмин, мемантин.
6. **Зависимости:** налтрексон, акампросат, бупренорфин, варениклин, дисульфирам, N-ацетилцистеин.
7. **Мигрень:** суматриптан и триптаны, эренумаб, атогепант, римегепант, топромат.
8. **Паркинсон/движение:** леводопа/карбидопа, прамипексол, ротиготин, амантадин,
   тригексифенидил, тетрабеназин.
9. **Сон:** мелатонин, суворексант, лемборексант, золпидем, залеплон, доксиламин.
10. **Ноотропы/прочее, с осторожностью:** модафинил, армодафинил, фенилпирацетам —
    только с честными предупреждениями о доказательности.

Правила для каждой новой записи:
- [ ] `doses[].note` содержит education-only (гарантируется merge, но писать осмысленно).
- [ ] Минимум один `pubmed` query, по возможности PMID первоисточника.
- [ ] Механизм с числами там, где они известны (Ki, EC50, t½, CYP).
- [ ] Флаги (`qt`, `serotonergic`, `sedating`, `dependence-risk` …) — по факту, не по памяти.
- [ ] Класс добавлен в `CLASS_RULES`, если у класса есть правила совместимости.
- [ ] `#/dev/audit` 12/12 после каждой партии в 20 записей.

**Приёмка Ф3:** 250 уникальных id, все проходят аудит, ни одного «заглушечного» текста.

- [ ] PMID к 20 самым опасным правилам взаимодействий: все МАОИ, серотониновый синдром,
      QT-пары, опиоид+габапентин, литий+НПВС.

**Приёмка Ф5:** ≥20 правил с реальными PMID, все открываются на pubmed.ncbi.nlm.nih.gov.

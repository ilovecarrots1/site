# NeuroDifference 3.0.0 — релиз

Справочник по нейрофармакологии, который целиком живёт в браузере.
Без аккаунта, без бэкенда, без трекинга. Бесплатно.

**148 соединений** в 55 классах: механизм, мишени, фармакокинетика,
диапазоны доз (только для образования — это написано в каждой сноске),
эффекты, предупреждения, флаги.

**2.5D-атлас мозга**: слоистый полупрозрачный SVG, 28 областей, зум камеры,
прямые ссылки вида `#/brain/amygdala`.

**10 нейромедиаторных систем**, 20 путей, 30 молекулярных мишеней, 29 органов —
всё связано между собой.

**Лаборатория взаимодействий**: 91 парное правило, 45 правил по классам,
флаги по QT, серотониновой нагрузке, порогу судорог, риску кровотечения.

**46 состояний** в 11 главах, 112 подтипов, 221 симптом, кросс-маппинг на
МКБ-9, МКБ-10 и МКБ-11. Ни одного пропущенного кода МКБ-11.

**59 показателей крови** в 11 группах, 306 связей с соединениями.
Диапазоны универсальные, без деления по полу.

**PK-калькулятор**: кривая полураспада, повторные дозы, наложение до пяти
соединений — видно накопление, а не «примерно представляешь».

**Стек (8 соединений), сравнение, план отмены, подбор по симптомам,**
карточки с интервальным повторением, XP, стрики, уровни.

**Живой поиск PubMed по 40+ миллионам записей** — MEDLINE, журналы, книги.
Результаты держатся в памяти 30 минут и никогда не пишутся на диск.

**Заметки** и история — локально, на устройстве.

**Экстренная вкладка**: красные флаги, серотониновый синдром,
нейролептический злокачественный синдром, первые шаги при судорогах.

Под капотом: без сборки, чистые ES-модули, ноль зависимостей, PWA с офлайном,
скины, свой акцентный цвет, уважение к `prefers-reduced-motion`,
самопроверка `#/dev/audit` (12/12).

Не медицинская рекомендация. Только образование.

Three classic causes of a blank page

  • Files landed outside the web root. On most shared hosting the served folder is public_html (or www/<domain>/public_html), not the FTP home directory. If every row below is 404, nothing is inside the served folder.
  • .htaccess breaks Apache. A 500 error on every request is almost always mod_rewrite / mod_headers missing. Rename it to .htaccess.bak and reload — the app works without it.
  • JavaScript served as text/plain. ES modules refuse to run then. Look for a red MIME note in the table below.

Fastest way to prove the build itself is fine: upload preview.html (one self-contained file, CSS and JS inline) and open …/preview.html. If that renders, the code is good and only the file layout is wrong.
